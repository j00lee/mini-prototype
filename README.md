# Little Sketch

A simple drawing app built with HTML, CSS, and JavaScript.

## Run

Run `npm start` and open http://localhost:4173, or open `index.html` directly in your browser. The local server uses Python 3. No npm dependencies are needed.

## Features

- Mouse, touch, and stylus drawing
- Brush colors, custom color picker, and adjustable size
- Eraser, undo/redo, and clear canvas
- Save your drawing as a 1600 × 1000 PNG
- Keyboard shortcuts: B for brush, E for eraser, Ctrl/Cmd+Z to undo, Ctrl/Cmd+Shift+Z to redo

Drawings live in the current browser page. Save an image before closing or refreshing.

Run `npm run check` to check JavaScript syntax.
